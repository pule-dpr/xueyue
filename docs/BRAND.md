# 雪约：品牌与设计系统

## 品牌定位

雪约不是普通网约车工具，也不是滑雪社交广场。它是把路线、空位、同行者和费用协商组织在一起的雪季通行工具。

## Logo

主文件：[2048px Logo](../design/logos/snowdate-reference-clean-2048.png)

画面包含：

- 白色雪服滑雪人
- 车头轮廓
- 交叉雪板与雾粉/香芋紫板面
- 荧光绿雪具边缘
- 浅蓝天空背景

使用规则：

- 保持人物、车头与交叉雪板的相对位置，不拆分单独使用。
- 浅色界面周围至少保留一个图标宽度的空白。
- 不拉伸、不裁掉人物头部或雪板端点。
- 商店图标使用 1024×1024 完整版本。

## 字体

- 中文使用系统无衬线：iOS Avenir Next / PingFang SC，Android sans-serif。
- 数字使用系统 condensed 字型以增强时间和价格识别。
- 页面标题 24–28px，正文 10–13px，辅助信息 8–9px。
- 正式开发继续验证系统字体缩放下的可读性。

## 布局

- 手机左右边距 20px。
- 卡片圆角 16–20px。
- 底部抽屉顶部圆角 27px。
- 页面默认左对齐，价格和结束时间可以右对齐。
- 地图页面优先展示道路与路线，覆盖层只承载路线摘要与底部操作。

## 文案

- 直接说明信息：“07:20 出发”“余 3 座”“最低 ¥50 / 人”。
- 不夸张承诺：“平台不收款”“未成交不锁座”。
- 错误信息说明原因和下一步。
- 安全和隐私说明保持具体、可理解。
