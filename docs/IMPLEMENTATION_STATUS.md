- 拼车结果卡
- 真实路线样例详情
- 申请人数和雪具
- 按人报价与总价计算
- 车主申请审核

- 同意、拒绝和一轮回价

- 通知未读角标、单条已读、全部已读与对应行程跳转

- 开发验证码、HMAC 摘要、会话令牌和用户资料接口
- 服务端行程、申请、回价、通知与 SQLite 原子锁座事务
- 发布拼车
- 我的加入 / 我发起的
- 本地持久化
- 分享行程
- 演示数据重置
- 选定 Logo 与 Android 图标
- 1024×500 商店横图
- 7 张 1082×2202 商店截图
- Android 权限精简与 Allow Backup 关闭

## 尚未接入

### 高德地图 Key

当前使用真实道路样例。生产版需要：

- 高德开放平台 Android Key
- 包名与签名 SHA1 绑定
- 高德地图 SDK config plugin
- 高德隐私政策与权限说明

当前地点选择在未配置高德 Key 时使用本地地点库和 OpenStreetMap Photon 地点联想，并允许自定义输入。配置 `EXPO_PUBLIC_AMAP_WEB_SERVICE_KEY` 后会优先使用高德地点搜索。正式发布前仍需要完成经纬度、行政区和路线坐标的统一接入。

### 账号与云端

当前已有本机资料、首次启动流程和可用服务端 API。配置 `EXPO_PUBLIC_API_URL` 后，首次启动会连接服务端；未配置时继续使用本地演示码。正式多人使用仍需要：

- 接入真实短信供应商、限流与风控
- 手机号换号、账号找回和会话吊销
- 把本机行程、申请和通知切换为服务端数据源
- 部署服务端数据库并迁移到生产托管数据库
- 实时订阅或轮询同步
- 远程推送；当前已有本机站内消息，重新安装后不会保留

### 真机与签名

当前开发机没有 Android SDK，因此未在本机生成 APK。可安装 Android Studio，或使用 EAS 云端构建。
