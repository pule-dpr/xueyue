# 雪约 1.0.0

首个 Android 版本，面向滑雪人群提供顺路拼车信息与同行协调。

## 主要功能

- 按出发地、雪场和日期查找拼车
- 地点关键词推荐、自定义地点和本机历史地点
- 查看真实道路样例、路线版本、接人点和预计时间
- 提交人数、雪具、上车位置和按人报价
- 车主查看加入后路线、绕行时间和总报价
- 车主同意、拒绝或发起一轮回价
- 乘客接受回价、再想想或撤回
- 已确认座位后递增路线版本
- 本机消息中心与未读状态
- 首次启动、账号资料和车辆资料

## 安全边界

- 雪约不提供在线支付、资金托管或承运担保
- 价格仅作为双方线下费用协商记录
- 未成交不会锁座
- 当前生产包默认使用本机数据；未配置生产 API 时不会把手机号标记为服务端已验证
