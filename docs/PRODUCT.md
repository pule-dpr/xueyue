# 雪约：产品定义

## 一句话

雪约帮滑雪人群找到从市区到雪场的顺路空位，并让车主在人数、雪具、路线和报价都合适时确认同行。

## 核心问题

滑雪场通常离市区较远，公共交通不便。车主有空座，乘客需要往返车辆，但现有群聊很难完成以下协调：

- 出发区域和时间是否真的顺路
- 几人同行、能带多少雪具
- 加入接人点后车主需要多绕多远
- 双方对费用分摊是否达成一致
- 接受申请后，所有成员是否看到同一条最新路线

## 用户角色

### 车主

- 发布出发地、雪场、日期和时间
- 设置余座、雪具位、最低价格和最大绕行
- 查看申请人的上车点、人数、雪具与报价
- 查看加入前后路线
- 同意、拒绝或回价

### 乘客

- 搜索雪场和日期
- 查看当前有效路线、价格和余位
- 填写人数、雪具和上车点
- 按人报价
- 接受车主回价、再想想或放弃

## 已确认规则

1. 多人申请作为一整组处理。
2. 待审核和回价阶段不占座。
3. 同意申请时原子校验余位与雪具位。
4. 成交后锁定价格和座位，并生成新路线版本。
5. 已成交成员始终查看当前有效路线。
6. 未成交时精确接人点脱敏。
7. 首发仅允许一轮回价。
8. 价格按人计算，平台不支付、不托管资金。

## 当前 MVP

- 首页推荐顺路行程
- 搜索和筛选
- 真实地图路线详情
- 申请人数、雪具和报价
- 车主申请审核
- 当前路线与加入后路线对照
- 回价后的乘客确认
- 发布拼车
- 我的行程与本地持久化
- 首次启动隐私确认、昵称和本地演示手机号设置
- 已保存的账号与车辆资料编辑

## 非目标

- 商业网约车调度
- 在线支付和平台担保
- 公开陌生人社交
- 私信聊天
- 实时定位
- 未经审核的用户公开内容

## 后续阶段

1. 手机号登录与云端同步
2. 高德地图 SDK 与真实路线计算
3. 推送通知
4. 邀请链接
5. 取消与席位冲突的完整服务端事务
6. 同行记录与可控的雪场社交
