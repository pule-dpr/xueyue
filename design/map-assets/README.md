# 地图设计样例

## 文件

- `changchun-songhuahu-route.jpg`：世纪广场到松花湖的当前路线
- `changchun-songhuahu-compare.jpg`：当前路线与加入接人点后的路线对比

## 数据来源

- 底图：通过 OpenStreetMap 官方地图视图截图生成。
- 道路路线：OpenStreetMap 数据经 OSRM 道路规划返回。
- 样例坐标：长春世纪广场至松花湖雪场。

## 使用范围

这些图片仅用于当前 UI 和单机演示，用于确认地图信息层级与路线对照方式。

正式 App 接入高德地图后，应使用高德返回的驾驶路线、里程、时间与途径点，并遵守其授权和署名要求。
