## 已确认的产品闭环

1. 车主发布拼车、人数和雪具容量、最低价格、路线条件。
2. 乘客按人数提交上车点与单人报价。
3. 车主查看加入后的路线、绕行和报价，同意、拒绝或提出一轮回价。
4. 乘客接受回价或放弃；未成交不锁座。
5. 成交后原子锁座、确认最终价格、生成新路线版本并通知成员。
6. 平台不支付，价格仅作为线下费用协商记录。
7. 拼车详情使用真实地图驾驶路线，不用装饰性地图代替。

## UI 候选方向

- **雪线车票**：以路线车票为核心，信息结构保留，但视觉不再是主方向。
- **山路信号**：以公路标识和高效数字为核心，适合更硬朗的户外工具气质。
- **雪场编组**：以同行者和组队关系为核心，更年轻，也更接近未来社交扩展。
- **马卡龙雪场**：用户反馈幼稚，不采用。
- **雪线节拍**：误读为整屏深色，不采用。
- **轻雪同行**：整体采用更克制的马卡龙配色，Logo 单独参考抖音/汽水音乐，并包含滑雪人与车、雪道寓意。
