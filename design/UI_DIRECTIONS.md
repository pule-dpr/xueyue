# 雪约 UI 方向提案

阶段：风格确认  
状态：等待用户选定方向后进入高保真设计

## 产品气质

雪约不是旅游内容社区，也不是网约车调度系统。它更接近一本由雪友共同填写的公路行车册：需要快速判断时间、路线、空位和价格，也需要对同车的人产生基本信任。

UI 的核心记忆点应该来自**路线本身**：起点、接人点、雪场、剩余空位和价格共同组成一张像车票又像雪场地图的行程卡。其他区域保持克制。

## 方向 A：雪线车票

- 关键词：可信、清楚、户外、像一张真正的冬季车票。
- 色彩：冰川墨绿、雾雪白、冰蓝、路线橙、雪票黄。
- 字体：目的地与大数字使用有编辑感的宋体；操作与正文使用清晰的无衬线字体。
- 结构：左侧时间轨道，中间路线与途经点，右侧价格和余位。行程卡不做普通 SaaS 白色圆角盒，而像一张带有打孔边和路线编号的车票。
- 动效：成交时路线线新增一个站点并延伸到目的地，作为唯一重点反馈。
- 风险：需要控制“车票”装饰感，不牺牲价格和人数识别。

## 方向 B：山路信号

- 关键词：运动、直接、效率、公路标识。
- 色彩：石墨黑、雪白、高亮黄、冰蓝、警示红。
- 字体：窄体数字、粗黑中文、接近交通标识的排版。
- 结构：用强对比色块和超大出发时间组织信息；价格像收费路段标牌，余位像车位计数。
- 动效：价格确认和余位变化使用硬切变化，不使用柔和渐变。
- 风险：容易显得过于硬朗，信任感和社交温度较弱。

## 方向 C：雪场编组

- 关键词：年轻、组队、活跃、雪场文化。
- 色彩：雪场蓝、荧光青、黑色、雪白、少量亮橙。
- 字体：几何无衬线、数字更圆润。
- 结构：同行者、空位、路线标签和价格以模块化编组呈现，强调“和谁一起走”。
- 动效：成员加入后头像与座位槽位组合变化。
- 风险：如果视觉过强，会削弱路线、价格、余位等关键信息，也容易更像社交产品。

## 方向 D：马卡龙雪场（用户反馈幼稚，不采用）

- 关键词：年轻、轻盈、友好、周末组队。
- 色彩：奶白、薄荷、草莓粉、香芋紫、奶油黄、雾蓝、深靛正文、莓果主操作。
- 字体：使用高字重无衬线，弱化车票的编辑感，标题更轻快直接。
- 结构：白色大圆角行程卡，路线、价格、座位和雪具用不同的低饱和功能块分组；座位用四个胶囊槽位展示。
- 地图：拼车详情使用真实地图路线，不以插画小地图代替；地图底板浅化，路线使用莓果色，途经点使用编号与马卡龙色区分。
- 风险：糖果色容易显得幼稚或轻飘，因此文字必须使用深靛，关键数字和按钮保证足够对比度。
- 结论：用户反馈整体偏幼稚，尤其不接受右上角圆形装饰和大幅口号，因此不再采用。

## 方向 E：雪线节拍（误读为整屏深色，不采用）

根据“参考抖音、汽水音乐风格”的反馈重新设计，作为当前主方向。

- 关键词：夜间、公路、音乐感、霓虹、年轻但不幼稚。
- 背景：整屏使用深黑到冷蓝的连续背景，不再用右上角散落圆形或局部渐变贴片。
- 色彩：近黑、电光青、荧光粉、信号黄绿、雪白。高饱和色只用于路线、关键数字和主操作。
- Logo：新图形“雪线节拍”，由三根高低的圆角竖线组成，类似音乐均衡器，也像雪峰和路线停留点。
- 字体：高字重无衬线，标题控制在 26–30px，不再用 40px 以上的口号占据首屏。
- 文案：首屏直接说“去松花湖”“周六 07:20”“余 3 座”，删除“周末上雪，顺路捎你”一类宣传式大标题。
- 卡片：使用一张全身量感的主路线卡，以电光青到黄绿的整块渐变承载目的地、路线、价格与余位；其余信息保持暗色和低装饰。
- 地图：详情页使用真实地图主视图，地图之上使用黑色悬浮条、路线颜色按霓虹青区分；真正接入地图后不保留当前示意底图。
- 风险：高饱和霓虹色不能大面积同时使用，必须用黑色和白色留出层级；霓虹色不能作为浅色文字直接压在马卡龙色块上。

Logo 规范见 [LOGO_DIRECTIONS.md](./LOGO_DIRECTIONS.md)。

## 方向 F：轻雪同行

根据用户澄清重新设计，作为当前主方向。

- 仅 Logo 参考抖音、汽水音乐的霓虹与高对比；整体界面仍然使用马卡龙配色。
- 整屏浅色背景采用薄荷、奶白、雾粉和少量薰衣草的连续过渡，不再散落装饰圆片。
- 降低甜腻感：主标题控制在 24–28px，文案直接陈述目的地、时间和余位；减少彩色胶囊数量。
- 主卡片使用白色或轻微雾面底色，路线用薄荷，价格用莓果色，座位用深色离散标记。
- Logo 采用“滑雪人 + 车 + 雪道”组合图形，高饱和色只集中在圆角 App 图标中。
- 地图详情保持浅色真实地图，使用白色信息卡而非深色全屏。
- 视觉原则：年轻来自色彩和图形，不来自卡通化装饰；信息密度和成熟度不能下降。

## 推荐组合

用户明确澄清：Logo 参考抖音/汽水音乐，整体依旧马卡龙。因此方向 F 取代 D 与 E 成为当前默认候选：浅色整屏马卡龙背景、克制的信息层级、醒目的“滑雪人 + 车”Logo。

推荐 Token 初稿：

| 角色 | 色值 |
| --- | --- |
| 深炭文字 | `#20273A` |
| 薄荷背景 | `#BCE8D5` |
| 雾粉背景 | `#FFE2E9` |
| 香芋紫 | `#DCD7F4` |
| 奶油黄 | `#FFF0B5` |
| 莓果主操作 | `#D95777` |
| Logo 霓虹色 | `#67F4E5 / #FF5B9D / #C8FF4D` |

字体建议：

- 目的地、页面标题：高字重 `Noto Sans SC` 或后续定制圆润无衬线。
- 正文、按钮、表单：`Noto Sans SC`。
- 时间、价格、座位数字：较窄的高识别数字字型。

布局原则：

- 卡片的骨架是路线，而不是装饰。
- 时间靠左、路线居中、价格和余位靠右，形成稳定的扫读顺序。
- 头像只用于建立信任，不做大面积社交展示。
- 薄荷用于路线和背景，莓果色用于价格与主操作，霓虹三色只出现在 Logo 内。
- 详情页以真实地图为主要视图，地图信息优先于背景装饰。
- 地图和路线必须先保证交通信息可读，再考虑艺术表现。

## 待确认项

- 是否以 F 轻雪同行作为正式主方向。
- 首屏更偏“找车”还是“我的待办”。
- 是否接受整屏浅色马卡龙背景与白色主路线卡。
- 拼车详情确认采用真实地图主视图，由高德地图提供道路与路线。
- 新 Logo“雪线同行”中滑雪人、车身与路线曲线的比例是否需要继续调整。
